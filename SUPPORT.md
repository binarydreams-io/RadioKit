# Support

Use [GitHub Issues](https://github.com/binarydreams-io/RadioKit/issues) for reproducible defects and focused feature requests.

Before you open an issue, test the latest released version.
Include the RadioKit version, Swift version, Apple platform version, and a minimal reproduction.
Describe the stream transport and codec, but do not publish private endpoints or credentials.

RadioKit support does not cover third-party stream availability, catalog accuracy, Apple account access, app signing, or App Store configuration.
Report security concerns through [SECURITY.md](SECURITY.md).
